# 🎬 Movie Recommender System

A **Machine Learning based Movie Recommender System** built with **Python and Streamlit**.
The app recommends similar movies based on the selected movie using **content-based filtering** and displays movie posters using the The Movie Database API.

---

## 🚀 Features

* Recommend movies based on similarity
* Fetch movie posters using TMDB API
* Interactive web interface with **Streamlit**
* Fast and simple movie discovery

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

---

## ▶️ Run the Project

Clone the repository:

```bash
git clone https://github.com/naveenkumarv16/MOVIE_RECOMMENDER_SYSTEM.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run main.py
```
